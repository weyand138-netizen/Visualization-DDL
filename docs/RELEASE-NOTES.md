# Visualization-DDL 1.1.0 — first public preview

First clean MIT source release with a new Git history. Includes the independent standard-library DDL calendar, focus and income dashboard, the AstrBot/QQ plugin, and an independently installable Python 3.11+ stdio MCP connector pinned to official `mcp==2.3.0`.

The connector provides four account-bound calendar tools, partial updates, full-snapshot conflict checks, transactional backend validation, request-ID retry deduplication and HTTPS/redirect protections. AIRI uses ordinary conversation; it does not require `/日程`, AstrBot or NapCat. The dashboard hides its AstrBot-specific AI planning entry when unconfigured.

Includes three English/Chinese guides, synthetic screenshots, configuration-preserving installers, backup instructions, cross-platform CI, source/history/archive privacy checks and a draft AIRI ecosystem proposal. No production database, QQ bindings, conversation history, credentials or old Git history is included.

Deployment guides: [case study](01-case-study.en.md), [AstrBot / QQ](02-astrbot-qq.en.md), [independent AIRI](03-airi.en.md). 中文：[实操记录](01-case-study.zh-CN.md)、[QQ 部署](02-astrbot-qq.zh-CN.md)、[AIRI 部署](03-airi.zh-CN.md)。

**Preview limits:** actual official AIRI and airi-HA desktop natural-language acceptance, fresh public HTTPS deployment and active real QQ message delivery remain unverified. Consult [validation evidence](VALIDATION.md) and Actions for tested scope. No active reminders, recurring events, embedded AIRI calendar or web/mobile-specific adapter. This is a community project; no upstream endorsement or organization transfer has occurred.
