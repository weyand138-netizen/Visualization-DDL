# Contributing / 贡献

Open an issue describing the proposed behavior before a substantial change. Keep the independent DDL, AstrBot and MCP boundaries intact. Run the dashboard and connector tests listed in README and the privacy check. Never test by writing to a real user's database. Document which runtime/version was actually tested; distinguish simulated integrations from live model/desktop tests.

Documentation changes should update English and Chinese counterparts. The dashboard currently uses Chinese UI copy. Contributions use the MIT license. Do not claim official AIRI affiliation. Read [PRIVACY.md](PRIVACY.md) before attaching screenshots, examples or logs.

较大改动先通过 issue 说明需求；保持三部分独立，运行测试与隐私检查。禁止使用真实用户数据测试或上传生产日志。双语文档同步更新，验证记录须如实说明测试环境。贡献采用 MIT 许可。
